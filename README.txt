HOW TO PUBLISH FREE WITH GITHUB PAGES:
1. Create/sign in to a GitHub account.
2. Create a new PUBLIC repository. Suggested name: gerasimos-despotakis
3. Upload all 3 files from this folder to the repository root.
4. Open repository Settings > Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Choose branch "main" and folder "/ (root)", then Save.
7. GitHub will display your public website URL after publishing.
8. Open the public URL on your phone and test:
   - phone number
   - email
   - LinkedIn
   - Save Contact
   - embedded CV
9. Use the public website URL to generate a STATIC QR code.

IMPORTANT:
Keep index.html, the PDF and VCF filenames exactly as supplied unless you also update the links inside index.html.
